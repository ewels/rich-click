Built on Click, the Python package for creating beautiful command line interfaces, and Rich, the Python library for rich text in the terminal.

Features

Attractive help output with minimal customisation required, and plenty of room to go further.

Rich formatting

Click help and error messages rendered with colour, panels and tables.

Same API as Click

Usage is simply import rich_click as click.

26 colour schemes, 6 formats

Mix any scheme with any format. Set it in code, or let users pick with RICH_CLICK_THEME.

Panels

Group commands and options into named panels.

Clear errors

Well formatted error messages that point users to the fix.

rich-click CLI tool

Prefix any Click or Typer command to richify someone else’s CLI.

Export HTML and SVG

Drop real help output straight into your docs.

Extensive customisation

Styles, text, layout and box formats are all configurable.

IDE autocomplete

Typed Click decorators for a smooth developer experience.

One line change

Swap your Click import and keep writing Click as normal. You can also opt in one command at a time, or run rich-click on a CLI you didn’t write.

Import as click

Change one line in your own CLI: import rich_click as click

or

Declarative

Keep importing Click and opt in per command: @click.command(cls=RichCommand)

or

Someone else’s CLI

Put rich-click in front of any Click or Typer command.

Design your own theme

Tweak colours and box styles in the browser, then copy the config straight into your CLI.
